Cloud Deployment Runbook

Step-by-step commands to build the Docker image and deploy onto Kubernetes

Phase 1

1. Local Development & Verification

Run and test the Express notice-board server locally before containerization:

Bash / PowerShell 
npm install && npm start
Phase 2

2. Containerize with Docker

Build the Docker image and run the isolated container on port 3000:

Docker Build 
docker build -t notice-board-app:latest .
Docker Run (Port 3000) 
# Make sure local npm start is stopped first to avoid port conflict
docker run -d -p 3000:3000 --name notice-board-container notice-board-app:latest
Phase 3

3. Deploy on Kubernetes Cluster

Apply deployment manifests with 3 replicas, liveness/readiness probes, and NodePort service:

Kubectl Apply 
kubectl apply -f k8s/k8s-all-in-one.yaml
Check Pods & Service 
kubectl get pods -l app=notice-board-app -o wide
kubectl get svc notice-board-service
Forward Port (Minikube / Docker Desktop) 
kubectl port-forward service/notice-board-service 3000:3000
